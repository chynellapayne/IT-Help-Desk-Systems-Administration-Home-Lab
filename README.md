IT Help Desk & Systems Administration Home Lab
Project Overview

This project is a hands-on IT Help Desk and Systems Administration home lab designed to simulate common technical support scenarios in a small business environment.

The lab focuses on troubleshooting real-world IT issues, documenting help desk tickets, administering Windows systems, working with networking tools, and applying basic cybersecurity practices.

Rather than only studying IT concepts, this project allows me to practice identifying problems, troubleshooting them, implementing solutions, and documenting the resolution process.

Objectives
Practice a structured IT troubleshooting methodology
Diagnose common Windows and network issues
Simulate and resolve help desk tickets
Practice command-line and PowerShell troubleshooting
Build Windows Server and Active Directory administration skills
Apply security concepts such as least privilege and account security
Document technical problems and resolutions clearly

Lab Sections
Help Desk Ticketing

Documentation of simulated support tickets including the reported issue, troubleshooting process, root cause, and resolution.

Network Troubleshooting

Hands-on troubleshooting using tools such as ipconfig, ping, tracert, and nslookup.

Windows Troubleshooting

Troubleshooting Windows user accounts, services, applications, system performance, and Event Viewer logs.

Active Directory

Administration of users, groups, organizational units, permissions, password policies, and domain-joined computers.

PowerShell

Using PowerShell for system administration, troubleshooting, and basic automation.

Security

Applying cybersecurity principles including least privilege, account security, logging, auditing, and investigation of suspicious activity.
